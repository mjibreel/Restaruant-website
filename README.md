# Restaruant-website

Mahalla Restaurant Website 🍽️
Project Overview:
The Mahalla Restaurant Website is a simple, user-friendly web application showcasing a restaurant's services, menu, and contact details. This project was developed as part of a web development assignment to demonstrate skills in building responsive and visually appealing interfaces using modern web technologies.

https://github.com/user-attachments/assets/8092c630-b308-4122-8c0d-189f0c857323


Key Features:

Home Page: A welcoming landing page with a hero banner introducing the restaurant's theme and a call-to-action button to explore the menu.
Menu Page: A detailed menu section displaying food items with prices and images for an enhanced user experience.
Login and Sign-up Page: Secure login and registration functionality for user access.
Profile Page: A personalized user profile that displays the user’s contact details and preferences.
Contact Page: A contact form for customers to get in touch, along with business location, email, and operating hours.


Technologies Used:

Frontend: HTML, CSS, and JavaScript for structure, styling, and interactivity.
